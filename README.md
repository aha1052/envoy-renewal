# Envoy 웹사이트 리뉴얼 프로젝트

Envoy Tours·Envoy Hostel 웹사이트 리뉴얼의 기획안, 와이어프레임, 진행 현황을 공유하는 정적 사이트(GitHub Pages).

- `index.html`: 공유 페이지(개요, 기획안, 와이어프레임, 진행 현황, 호스텔)
- `wireframes/`: 와이어프레임(Envoy Tours 10종, Envoy Hostel 8종)
- `tools/`: 원본 조각(hub-fragment.html)과 와이어프레임 변환 스크립트(conv.py → clean.py → images.py 순), 호스텔 와이어프레임 생성 스크립트(hostel_wf.py)
