# Envoy 웹사이트 리뉴얼 프로젝트

Envoy Tours·Envoy Hostel 웹사이트 리뉴얼의 기획안, 와이어프레임, 진행 현황을 공유하는 정적 사이트(GitHub Pages).

- `index.html`: 공유 페이지(개요, 기획안, 와이어프레임, 진행 현황, 호스텔)
- `wireframes/`: 와이어프레임(Envoy Tours 15종, Envoy Hostel 10종). Envoy Tours 와이어프레임은 HTML 파일을 직접 수정
- `tools/hostel_wf.py`: Envoy Hostel 와이어프레임 생성 스크립트(`python3 tools/hostel_wf.py`)
- `tools/doc2html.py`: Claude Doc 변환 스크립트
